    Note over Client, MV: Add Movie Flow
    Client ->> API: POST /movies/ {movie_data}

    Note over Client, MV: Update Movie Flow

    MRepo ->> MRepo: rebuild_collection()
    MRepo ->> MV: UPSERT vector
    MRepo -->> MS: success
    MS -->> API: success
    API -->> Client: {"message": "Movie updated"}
